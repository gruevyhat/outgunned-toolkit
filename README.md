# Outgunned Toolkit

An unofficial, browser-based toolkit for creating heroes and crews and running missions for **Outgunned** by Two Little Mice.

## Development

```sh
cd app
npm install
npm test
npm run dev
```

`npm run build` creates the GitHub Pages build. `npm run build:html` creates the network-free, single-file build at `play/outgunned-tools.html`.

The source books are not distributed with this project. All shipped rules data is page-cited and limited to mechanics and short paraphrases.
